# 🚀 LipiTUM Internship: Food Metabolites and Disease Risk

Internship project at LipiTUM (Technical University of Munich).

## 💻 What I did

- Parsed and integrated large biological databases (FooDB, HMDB, Exposome-Explorer) using Python (pandas, ElementTree XML).
- Built and queried a knowledge graph in Neo4j AuraDB linking dietary metabolites to disease and cancer risk.

## 🛠️ Tools

Python, pandas, ElementTree, Neo4j (AuraDB)

The databases used are publicly available.
